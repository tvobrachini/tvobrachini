## Open-source projects

- **[GRC Audit Swarm](https://github.com/tvobrachini/grc-audit-swarm)** — Research prototype that drafts an IT audit across Planning, Fieldwork and Reporting, with 13 deterministic audit-methodology checks, a cross-model QA review, and human approval gates between phases. Collects read-only AWS evidence, stores it in a SHA-256 evidence vault, and exports OSCAL 1.2.1 Assessment Results.
- **[SCF Auto-Crosswalker](https://github.com/tvobrachini/scf-auto-crosswalker)** — Suggests Secure Controls Framework (SCF) control IDs for IT policies, AWS Security Hub findings and audit scopes, for human review, and checks a control list against frameworks such as SOC 2 per requirement (gap analysis, no language model). CSV and OSCAL export.
